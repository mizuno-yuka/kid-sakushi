# 目のふしぎ（kid-sakushi）

子どもたちが「錯視」を体験できるウェブサイトです。スクリーンに映して、発表者が操作しながら使うことを想定しています。

- 10個の錯視を、ステップを追って体験できます
- 小学2年生までに習う漢字は漢字で書き、すべてふりがなを付けています
- ネットがなくても動きます（HTML / CSS / JavaScript とフォントだけ）

## 使い方

`index.html` をブラウザで開きます（フォルダごと保存してください）。

| 操作 | キー |
|---|---|
| つぎへ | `→` / `Space` / `Enter` |
| もどる | `←` |
| もくじへ | `Esc` |
| すきな錯視へ（もくじ） | `1`〜`0` |
| ぜんがめん | `F` |

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | デザイン（レトロポップ、色覚の多様性に配慮した配色） |
| `illusions.js` | 錯視の図と、ステップごとの説明文 |
| `patterns.js` | もくじカードの絵 |
| `app.js` | 画面の切り替え・操作 |
| `fonts/` | LINE Seed JP（SIL Open Font License） |

## 説明文の書き方

`illusions.js` の文章では、`{長|なが}` のように書くとふりがな（ルビ）になります。
